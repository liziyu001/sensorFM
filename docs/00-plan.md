## 2. 已知事实

- SensorFM 的**数据、权重、代码均未发布**，严格复现不可能。
- 但**方法复现可行**：论文给出了完整的架构、掩码策略、优化器和评估协议。
- 最接近的公开替代：**OpenMHC**（Stanford）开源了 LSM-2 的可复现实现，带约 6,700 万小时数据、11,894 人和 14 个 checkpoint。
- 公开数据的规模远小于论文的 20 亿小时；**合成数据**可以用来验证代码正确性和 scaling 趋势。
- 论文的核心结论是"模型 + 数据同步放大 → 下游线性变好"，但基线偏弱、标签多为自报，结论需要打折。

## 3. 学习目标（当前阶段）

不是"复现论文"，而是回答四个问题：

1. **这个模型到底怎么设计的？**
   - 一个 24 小时窗口如何变成 2,448 个 token？
   - 为什么要按"20 分钟 × 1 通道"切 patch，而不是混合通道？
   - AIM 的 mask 如何构造，损失为什么只在"人工掩码且原本有观测"的位置计算？
   - 编码器和解码器的形状、层数、位置编码分别是什么？
2. **它为什么可能有效？**
   - 缺失即信号 vs 插补/丢弃。
   - 冻结编码器 + 线性探针说明了什么？
   - scaling 的因变量和自变量分别是什么？
3. **哪些部分是真正的创新，哪些是标准组件？**
   - ViT-1D、MAE、Transformer block、线性探针都是成熟组件。
   - 真正的差异在 token 化、AIM、数据规模和评估协议。
4. **如果要做，最小可行实验是什么？**
   - 合成数据 + XXS 模型 + 单 batch 过拟合。
   - 用已知 latent 验证"表征确实学到了结构"。

## 5. 数据策略（暂定）

### 第 0 层：合成数据
- 已知 latent（睡眠债、压力、活动水平、体温节律、心率基线）。
- 34 通道分钟级观测 =  circadian 基线 + 状态驱动 + 自回归 + 噪声。
- 四种缺失机制：MCAR、MAR、连续块缺失、整通道缺失。
- 用途：代码正确性、缺失消融、scaling 曲线。
- **边界：只能证明方法，不能证明对真实健康有效。**

### 第 1 层：小真实数据
- WESAD（15 人，PPG/EDA/皮温/ACC）、MMASH（22 人）、GalaxyPPG（24 人）、UBFC-Phys（56 人）、Sleep-EDF。
- 用途：特征提取、时间对齐、下游评估协议。

### 第 2 层：中等真实数据
- OpenMHC（~6,700 万小时，11,894 人）、GLOBEM（497 人，4 年）、LifeSnaps（71 人）、PMData（16 人）。
- All of Us / UK Biobank：需申请，周期长，先不阻塞。

### 第 3 层：大规模
- 公开数据 + 合成数据 +（如果有）公司自有数据。
- 公开数据天花板约 10^8–10^9 小时。

### 关键方法点
不同数据集模态不一致。**用 AIM 把"这个数据集没有这个通道"当作 inherited missingness**，从而把异构数据集拼成一个语料。这是一个值得记录的研究角度：*cross-dataset pretraining with modality-level missingness*。

## 6. 评估口径（先定，避免训完不知道看什么）

- 重建：held-out observed tokens 的 MSE。
- 插补：随机 80%、时间块 10/30/60 分钟、整通道 2/6/12 通道；对比 mean/NN/linear。
- 下游：冻结编码器 → person-level mean+std → PCA-50 → 逻辑/线性回归 → 5 折 person-independent。
- 基线：人口学、680 维手工特征、XGBoost。
- 标签效率：10%–100%。
- 工程指标：tokens/s/GPU、MFU、数据加载等待时间、故障恢复。

## 7. 工程原则

1. **形状优先**：每个模块先写清楚输入/输出张量形状，再写实现。
2. **纯函数优先**：patchify / mask / loss 都是可单测的纯函数。
3. **配置驱动**：模型规模、patch 大小、掩码比例放 YAML。
4. **单卡代码即多卡代码**：不写两套；DDP 只是启动方式不同。
5. **可复现**：seed、shard、fold 固定；checkpoint 存 RNG 状态。
6. **先小后大**：XXS 跑通再谈 B。
